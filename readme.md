# Goals

Define cycling goals.

- Distance
- Duration
- Calories
- Power
- Average power
- Normalized power
- Speed
- Average speed
- Cadence
- Average cadence
- Heartrate zone
- Average heartrate zone
- Intensity Factor
- Traning Stress Score
- Total ascent
- Total descent

Display up to 10 goals as:

- Vertical bars
- Horizontal bars
- Proportional segments

With optional label and value.
Different options per datafield size possible.

## Presets

Use presets to easy set the individual goals.

- First select distance or duration
- Define suffer factor
- Choose:
    - Recovery
    - Casual
    - Weight loss
    - Endurance
    - Cardio
    - Short and fast
- Click again to apply

## Advanced

Cadence counter: x seconds not pedaling will show details.

HSP breakpoint: 1-255. Default 127.5, decision breakpoint to display white or black text on a color. Colors below HSP breakpoint will have white text, the others black text.
If some colors have black text but still appear dark (garmin color + sunglasses), consider changing HSP to a higher value (ex. 150) so more colors are considered dark.

Show HSP value: Show calculated hsp value in top right corner (only for Proportional segments).
